# Texture Slicer

用于将长图、大图或规则图集切成独立 PNG 的 Unity 编辑器工具。支持重叠分块、行列均分、透明裁剪、预览中排除切片，以及记录原图位置的 JSON 清单。

需要 Unity 6000.0 或更新版本，无额外包依赖，不包含运行时代码。

## 使用

菜单：**Tools → UniKit → Texture Slicer**。

1. 将项目中的图片拖入左侧输入框；也可以先在 Project 中选中图片，再打开工具。
2. 选择切割方式、尺寸或行列数。右侧自动显示切片边界与数量。
3. 按需开启透明边裁剪、跳过全透明切片，并设置透明阈值。
4. 点击预览中的切片可排除或恢复。使用“适应”、`1:1`、缩放滑条和滚动条检查细节。
5. 选择普通纹理或 Sprite 输出，点击“选择目录并导出切片”，选择当前项目 Assets 内的目录。

无需先创建配置资源。窗口保留自己的参数，切换来源会重新计算预览；源资源重新导入后也会刷新。更改参数后，停止调整约 0.3 秒再重算，拖动滑块时不反复扫描大图；等待期间保留旧预览并禁用导出。计算取消或失败时，提示旁会显示“重试”按钮。重新计算会重置手动排除的切片；存在手动排除的切片时，预览栏才显示“恢复选择”；自动跳过的全透明切片不会因此重新选中。

## 切割规则

| 模式 | 行为 |
| --- | --- |
| 按最大像素尺寸 | 按指定宽高切割，末尾块保留剩余实际尺寸。支持分别设置 X、Y 方向的重叠像素。 |
| 按行列数均分 | X 为列数，Y 为行数，完整覆盖图片；不能整除时，同方向切片最多相差 1 像素。此模式不使用重叠参数。 |

重叠像素必须非负且小于切片对应尺寸。例如 8 像素宽的图片，切片宽 5、重叠 2，会生成 `[0, 5)` 与 `[3, 8)` 两块，不再多出重复覆盖末尾的窄片。重叠区域会保留在相邻两张图片中，拼接时请使用清单中的原图坐标。

- 行号自上而下，列号自左向右；文件编号从 0 开始，预览标签从 1 开始。
- Alpha 小于或等于阈值的像素视为透明；裁剪只移除外围空白，不修改剩余像素的 Alpha。
- “裁掉透明边缘”和“跳过全透明切片”独立控制。
- 关闭“跳过全透明切片”时，完全透明的块保留原始切片尺寸，不生成零尺寸文件。
- 蓝框为原始切片范围，绿框为透明裁剪后的范围，暗色块不导出。
- 重叠区域点击时，以后绘制的切片为准。

## 像素来源

**PNG、JPG、JPEG 直接解码原文件**，不受 Unity 导入时的 Max Size、压缩和 Read/Write 设置影响。PNG 保留原文件像素与透明度；JPEG 本身不包含透明通道。

其他 TextureImporter 图片格式通过 GPU 回读当前导入纹理，使用导入后的尺寸与颜色。窗口会明确显示采用哪种来源、实际处理尺寸。需要这些格式的原始分辨率时，请先转换为 PNG 或 JPG。

预览和输出的 Unity 导入设置沿用源图片的 sRGB 标记。原文件读取保留编码值；GPU 回读对 sRGB 纹理使用 sRGB 目标，对线性数据纹理使用线性目标，避免额外 Gamma 编码。

工具不修改源图片和 `.meta`，不会临时开启 Read/Write。为控制预览和像素缓存的内存开销，单次处理限制为 6400 万像素，单边还受当前显卡最大纹理尺寸限制；每个方案最多 4096 块。像素裁剪不保留源文件的 EXIF、ICC 等文件元数据。

## 输出与取消

每次导出创建新的 `图片名_slices` 文件夹，已有同名目录时自动递增，不覆盖旧文件。

```text
Picture_slices/
├── Picture_r000_c000.png
├── Picture_r000_c001.png
└── slices.json
```

输出 PNG 使用无压缩、无 Mipmap、原像素尺寸的导入设置；过滤模式沿用源纹理。选择 Sprite 时使用 Single 模式，PPU 沿用源导入设置、Pivot 使用 Unity 默认中心。此工具按图片区域切割，不复制源 Sprite 的切片、Border 或自定义 Pivot。

透明扫描和导出提供可取消的进度条。透明扫描每 32 行提供检查点，进度窗口最多每 50 毫秒更新一次，单张大切片内部也可响应取消。取消或失败会清理本次输出目录，之前成功的导出不受影响。单次图片解码、GPU 回读和 Unity 导入调用不能中途打断，取消会在后续处理检查点生效。

## 坐标清单

建议开启“导出坐标清单 JSON”，尤其是在透明裁剪或重叠切割后需要还原原图布局时。

清单包含源资源路径、GUID、实际处理宽高、切割参数及全部切片。每块记录：

| 字段 | 含义 |
| --- | --- |
| `Row` / `Column` | 从左上角开始的行列编号，从 0 开始。 |
| `Cell` | 透明裁剪前的原图矩形。 |
| `Content` | 实际输出矩形，仍使用原图坐标。 |
| `Included` | 是否参与本次导出。 |
| `Empty` | 启用透明检测时，是否被判定为全透明。 |
| `File` | 相对于输出目录的 PNG 文件名；未导出时为空。 |

矩形格式为 `{ "x", "y", "width", "height" }`，坐标原点在原图**左下角**。如果 UI 使用左上角坐标，位置换算为 `left = Content.x`、`top = Height - Content.y - Content.height`。

## 实现

- `TextureSlicerWindow.cs`：左右布局、交互预览与导出入口。
- `TextureSliceLayout.cs`：切割几何、透明检测和边界裁剪。
- `TextureSliceIO.cs`：源文件读取、PNG 导出、导入设置和 JSON 清单。

预览和导出共用同一份切片结果。已在 Unity 编辑模式验证非整除覆盖、重叠尾片、透明处理、原始分辨率读取、像素坐标、手动排除、输出设置、清单和取消清理。
