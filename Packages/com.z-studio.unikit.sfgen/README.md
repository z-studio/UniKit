# Sprite Font Generator（SFGen）

将美术制作的 Sprite 纹理、散图或 SpriteAtlas 转换为 **UGUI Text** 和 **TextMeshPro** 可以直接使用的彩色位图字体。适合艺术数字、分数、价格、倒计时及固定字符集的标题。

工具提供字符映射检查、图集与文字预览、排版调整和制作配置保存。无需额外的 TTF/OTF 基础字体，也无需开启图集的 Read/Write。

## 环境与入口

- Unity 6000.0 或更新版本。
- 依赖 `com.unity.ugui`（包含 TextMeshPro）和 `com.unity.2d.sprite`。
- 菜单：**Tools → UniKit → SFGen**。

生成器仅在编辑器中运行。输出使用包内的 `UniKit/Sprite Font` Shader，支持彩色图集、UI 顶点颜色、Mask 和 RectMask2D；无需为了生成字体导入 TMP Essential Resources。项目自身的 TMP 默认设置仍按 TMP 的正常流程配置。

## 五步创建字体

窗口采用左右布局：左侧编辑 Sprite 字符映射和排版参数，右侧实时预览，两栏独立滚动；底部保留生成与资源定位按钮。

窗口顶部的“新建”会打开保存对话框，创建并打开一份独立的制作配置；取消对话框不会改变当前配置。也可以直接编辑初始面板，在首次生成时保存配置。

1. **选择来源**：选择 Sprite 纹理（Single / Multiple）、散图 Sprite 或 SpriteAtlas。散图支持拖入 Sprite、图片或文件夹；SpriteAtlas 直接读取 Objects for Packing 中的资源。Multiple 图片需先在 Sprite Editor 中切片并 Apply。
2. **填写映射**：在需要使用的 Sprite 缩略图旁填写一个字符。例如在图片“1、3、9”旁分别填入 `1`、`3`、`9`，其余输入框留空。
3. **核对映射**：确认缩略图与字符对应正确。留空的切片不参与生成，不要求使用连续切片；“显示顺序”只调整列表排列，不改变映射。至少填写一个字符，同一字符不能重复分配。
4. **调整排版**：选择生成类型和设计字号。通过文字预览检查结果；需要时展开“间距与基线”调整字距、行距及空格宽度。
5. **保存并生成**：点击“保存配置并生成字体”，在 `Assets` 内选择制作配置的保存位置。字体自动保存在同一目录。

例如保存 `Assets/Fonts/Score.asset`，选择同时生成两种字体后会得到：

```text
Assets/Fonts/
├── Score.asset               # 制作配置，双击继续编辑
├── Score Text.fontsettings   # UGUI Text 的 Font
└── Score TMP.asset           # TextMeshPro 的 TMP_FontAsset
```

每份字体的材质内嵌在自己的资源中。纹理来源直接引用输入图片；散图和 SpriteAtlas 来源会额外生成 `Score Atlas.png`，两种字体共用该图片。更新时保留输出资源的 GUID。请保留字体纹理及其 `.meta`，工具不会修改源图片的导入设置。

## 三种来源

- **Sprite 纹理**：适合已经排好的字符图集，支持 Single 和 Multiple。
- **散图 Sprite**：将所需 Sprite、图片或文件夹拖入窗口，也可从 Project 选择后点击添加；展开列表可移除项目。不同图片中的同名 Sprite 可分别映射。
- **SpriteAtlas**：选择现有图集，支持其中的 Sprite、图片、文件夹和变体的主图集。无需进入运行模式，也无需先执行 Pack Preview。

散图与 SpriteAtlas 会合成为字体专用图集。预览仅使用临时纹理，点击生成时才保存 PNG。SpriteAtlas 使用原始 Sprite 资源及其当前图片导入尺寸，重新按矩形排列，不沿用 Atlas 的旋转、紧密打包、分页和变体缩放。透明留白会保留，原 Atlas 重新打包不会改变字符绑定。

## 在 UI 中使用

**UGUI Text**：把 `Score Text.fontsettings` 拖入 Text 组件的 **Font** 字段，先使用 Normal 样式和白色文本颜色检查效果。无需单独指定材质。

**TextMeshProUGUI**：把 `Score TMP.asset` 拖入 TMP 文本组件的 **Font Asset** 字段。生成的是可以直接输入 `0123` 等文字的 Font Asset，不是需要 `<sprite>` 标签的 Sprite Asset。

文本颜色会与图集颜色相乘。白色保留图集原色；黑色会使字符变黑。文字字号可以在组件上调整，但位图放大后仍受原图分辨率限制。

## 字符与切片的对应规则

映射以 Sprite ID 保存。切片改名或切换显示顺序后，对应字符保持不变。每页显示 8 个切片，可用上一页、下一页继续填写。


| 设置 | 规则 |
| --- | --- |
| 名称自然排序（默认） | 按切片名称排序，例如 `digit_2` 排在 `digit_10` 之前。 |
| 来源顺序 | 纹理使用 Sprite Editor 数据顺序，散图使用列表顺序，SpriteAtlas 使用来源收集顺序；不代表画面上的阅读顺序。 |
| 按行从上到下，行内从左到右 | 以每行最高的切片为参照，垂直重叠达到较矮切片高度的一半时视为同一行，再按横坐标排序，兼容较矮的符号。适合行与行分隔清晰的图集；跨行或交错排列建议按名称排序。散图和 SpriteAtlas 使用合成图集的位置。 |

- 普通空格 `U+0020` 自动生成，不需要切片；宽度由“空格宽度”决定。
- 每格只允许一个 Unicode 码点；支持的 emoji 代理对视为一个字符。不能在一个输入框里填入一串文字。
- 留空或只填空白会跳过该 Sprite；未参与生成的切片也不参与字号计算。
- 删除或重新切片导致 Sprite ID 失效时，工具会提示。点击“清除失效映射”后，为新切片重新填写字符。
- 调整来源会保留映射，已移除的 Sprite 可通过“清除失效映射”处理。散图与 SpriteAtlas 中的同一个源 Sprite 共用绑定；与直接纹理模式切换时需重新填写映射。
- TMP 支持补充平面 Unicode 字符，例如某些 emoji；每个 Unicode 码点对应一个切片。
- UGUI Text 的旧字体接口限制为 BMP 字符。字符包含补充平面码点时，请选择仅生成 TMP。
- 组合字符、变体选择符和 ZWJ 序列不会自动合成为一个字形；这不是复杂文字塑形工具。

## 排版参数

所有尺寸均以“设计字号”下的像素为单位，文本组件改变字号后按比例缩放。

| 参数 | 作用 |
| --- | --- |
| 设计字号 | 字体的度量基准，同时是最高字符的目标高度。建议接近原始图集字符高度。 |
| 统一字符高度 | 开启时，每个切片等比缩放到设计字号；关闭时，所有切片使用同一缩放比例，保留大小差异。仅改变显示尺寸，不改变 UV。 |
| 基线距底部 | 默认 0，即底边对齐基线。增大后字形整体下移，用于给下伸部预留空间。 |
| 额外字距 | 添加到每个可见字符的前进宽度，可为负，但最终前进宽度必须大于 0。 |
| 额外行距 | 行高为“设计字号 + 额外行距”。文本组件仍可在此基础上调整行距。 |
| 空格宽度 | 空格的前进宽度，不绘制图片。 |

预览文字留空时显示全部已映射字符；输入框支持 Enter 手动换行，文字超出预览宽度时也会逐字自动换行。每行蓝线标记基线，“额外行距”会直接反映在各行之间。预览高度按排版后的行数计算，上下各留 8 像素边距，并与下方图集保持间隔。未映射字符以空白占位并提示；宽于整行的单个字形会被裁切。此预览不模拟 TMP 的单词换行和富文本规则。

切片中的透明留白也属于字形尺寸。工具不自动裁边，也不使用 Sprite Pivot 计算基线。如果大小写、标点或下伸部需要不同的位置，建议在美术图集中用一致的字格和透明留白表达，并关闭“统一字符高度”。

## 修改已有字体

双击制作配置，修改参数后点击“生成 / 更新字体”。工具重新读取当前切片，并原地更新字体及内嵌材质，保留 GUID 和对象引用，已绑定字体的组件无需重新指定资源。

- 图集切片改动后先在 Sprite Editor 中 Apply，再重新生成。
- 更换图集或修改导入尺寸后也应重新生成，以更新像素坐标和字体度量。
- 配置和输出可以在 Unity Project 窗口中移动或重命名；更新通过保存的引用定位输出。
- 若要制作独立变体，可以在 Project 窗口复制配置。新配置首次生成会创建自己的字体，不覆盖原配置的输出。
- 切换生成类型只更新选中的类型，已生成的另一种字体会保留。
- 同名文件被其他资源占用时会拒绝生成。生成资源使用自己的内嵌材质，替换为外部材质后需恢复再更新。
- 制作配置不是运行时组件，业务代码无需依赖它。

## 图集建议与限制

建议使用透明背景、关闭 Mip Maps，并根据画面风格选择 Point 或 Bilinear 过滤。高压缩率、过小的 Max Size 和切片边缘缺少透明间隔都可能影响清晰度；这些设置由使用者控制，工具不会擅自修改源图片。

散图与 SpriteAtlas 当前合成为一张图集，上限为 8192（同时受显卡纹理上限限制）。超出容量会提示拆分配置，不会静默缩小图片；未映射的来源 Sprite 仍占用合成图集空间，大批量来源建议先移除不需要的 Sprite。

这是一套**静态位图字体**制作工具：只有映射过的字符有对应图形，不动态补字，不生成 SDF，也不提供 SDF 描边、发光等效果。描边和阴影可以预先绘制在字符图片中。建议按原始设计字号附近使用，避免过度放大。

## 实现与验证

- `Editor/SpriteFontWindow.cs`：窗口、参数编辑、预览与制作流程。
- `Editor/SpriteFontSettings.cs`：制作配置及其 Inspector。
- `Editor/SpriteFontSource.cs`：来源读取、稳定标识和临时图集合成。
- `Editor/SpriteFontBuilder.cs`：字符校验、切片映射、字体度量和资源生成。
- `Shaders/SpriteFont.shader`：两类 UI 字体共用的彩色位图 Shader。

## Sprite Atlas 编辑器工具

菜单 **Tools → UniKit → Sprite Atlas Tools** 提供三个独立入口，均在非运行模式使用：

- **SpriteAtlas 导出 TMP Sprite Asset**：生成 PNG、TMP Sprite Asset 和内嵌材质。用于 `<sprite name="名称">` 标签，不是 SFGen 的 TMP Font Asset；要求源 Sprite 名称唯一，并已导入 TMP Essential Resources 中的 Sprite Shader。
- **SpriteAtlas 导出 SpriteSheet**：生成 Multiple 模式 PNG，并写入切片、Pivot 和 Border。
- **Sprite 图片拆分为散图**：选择图片时导出全部切片；选择 Sprite 子资源时仅导出该切片，支持批量选择。保留 Pivot 和按导入尺寸缩放后的 Border。

执行时选择当前项目 `Assets` 内的输出位置。每个输入创建独立的新目录，重复导出不会覆盖之前的资源；失败时清理当前输入的新目录，已成功导出的其他输入保留。源图片的 Read/Write 和其他导入设置保持不变。

SpriteAtlas 导出与 SFGen 使用同一套原始资源读取和合图逻辑，不依赖 Pack Preview 或运行时打包结果；导出的排列、尺寸遵循源图片导入设置，不沿用 Atlas 的旋转、紧密打包、分页或变体缩放。单张合成图集容量限制同上。
